# Eclipse relic artwork

The current landing-page artwork was supplied by the user as `0c47c1e2-a4c7-4693-aae4-90ad276654f2.png` and copied unchanged into the project.

- Current asset: [eclipse-relic.png](eclipse-relic.png), 1672 × 941.
- Hugo generates 960px (quality 90) and original-size 1672px (quality 95) WebP variants. A centered 3:2 frame, capped at the available hero height, uses proportional cover scaling to preserve the symmetrical composition with a light side crop.
- CSS tones the brass down to muted gold, blends black shadows into the page background, and softens the edges with an oval fade. The supplied PNG is unchanged.
- A restrained six-second glow follows the eclipse rim and the smaller central light. Ten tiny gold particles drift slowly around the artwork. Reduced motion keeps the glow steady and hides the particles.
- The previous artwork is recoverable from Git history; only the active artwork is kept in this asset directory.
